# Real Estate Analytics Dashboard

## Project Overview

This project is a comprehensive Real Estate Analytics Dashboard developed using Power BI.

The dashboard analyzes the performance of multiple real estate projects and provides insights into unit sales, collections, outstanding balances, project completion, and overall financial performance.

The project includes an interactive landing page, a global overview, date analysis, and detailed pages for individual real estate projects.

## Key Features

- Interactive project navigation
- Global performance overview
- Sales and collection analysis
- Outstanding balance analysis
- Project completion tracking
- Date-based analysis
- Individual project performance pages
- Light and dark dashboard themes

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- HTML & CSS
- Data Visualization
